きょうのタスク  

アイコンに「今日の残りタスク数」を表示するToDoアプリ（PWA）。  
Google Keepの置き換え。PC（アイコンに件数表示）とiPhone（出先での確認・操作）で同じデータを使う。  

────────────────────────

■ どんなアプリか  

・Keepのような色つきの列（リスト）にタスクを並べて管理する  
・アプリのアイコン（タスクバー／Dock）に、今日やることの残り件数が数字で出る  
・完了するとすぐ数字が減り、0件になると数字が消える  
・ポップアップ通知は出さない。知らせる手段はアイコンの数字だけ  
・見た目はクラシックRPG風（ドット絵の風景、黒いウィンドウ、ドット文字）。タスクを完了するとけいけんちが入り、レベルが上がる。右上に勇者のプロフィール、たまに たからばこ  
・タスクとは別に、件数に入らない「メモ」（付箋）も置ける。メモのリスト（列）は自由に増やせる  
・Googleアカウントでログインすると、PCとiPhoneでデータが自動で同期される  
・iPhoneではリストをタブで切り替える画面になる（アイコンの数字は出さない）  

────────────────────────

■ つくり（構成）  

HTML／CSS／JavaScriptで動くWebアプリ。自前のサーバーは持たない。  
アプリ本体はGitHub Pagesで公開し、PCはChrome／Edgeから「インストール」、iPhoneはSafariから「ホーム画面に追加」して使う。  
データはFirebase（Googleのクラウドデータベース）に保存し、PCとiPhoneで共有する。  

ファイル一覧  
・index.html … 画面の骨組み（ボード、編集画面などのダイアログ）  
・style.css … 見た目（パステル色の付箋カード、ボタンなど）  
・art.js … ヘッダーと下の帯のドット絵（キャラ・モンスター・風景）。キャラは定番のRPGの職業をもとにしたオリジナル  
・version.json … いま公開しているバージョン番号（アプリが「新しい版があるか」を確かめるのに使う）  
・app.js … 画面の動き（件数計算、繰り返し、日付の切り替え、スマホ表示など）  
・sync.js … クラウド同期（Googleログイン、Firebaseへの保存・受信）。Firebaseの接続設定（firebaseConfig）もここ  
・firebase-sdk.js … Firebase公式のプログラム（v12.19.0）を1ファイルにまとめたもの。中身は触らない  
・firestore.rules … Firebaseの「本人だけ読み書きOK」のルール（Firebaseの画面に貼る用。アップしなくても動く）  
・manifest.webmanifest … 「インストール」できるようにするための設定（アプリ名、アイコン、色）  
・sw.js … Service Worker。オフラインでも起動できるようにファイルを保存しておく  
・icons/ … アプリのアイコン画像（192px、512px、マスカブル用、favicon など）  
・公開手順.md … GitHub Pagesへの公開とインストールの手順  
・README.md … このファイル  

データの保存先  
・Firebase（プロジェクト名：kyou-task）の Firestore に保存。場所は users/（ログインした人のID）/ の下  
　lists（リスト）／tasks（タスク）／rules（繰り返し設定）／memos（メモ）／meta（初回作成日、けいけんち、プロフィール、宝物）  
・Firebaseのルールで、jsakai@thomas-gr.com でログインした本人しか読み書きできないようにしている  
・各端末のブラウザ内にも控え（localStorage「kyou-task-data-v1」と Firestore のキャッシュ）を持つので、電波がなくても見られる・操作できる。つながったら自動で送られる  
・GitHubに公開されるのはプログラムだけ。他の人がURLを開いてもログイン画面が出るだけで、データは見えない  
・firebaseConfig（apiKeyなど）はプログラムに書く前提の値で、見られても問題ない。データを守っているのはFirebase側のルール  

使っている主な仕組み  
・Badging API … アイコンに数字を出す（navigator.setAppBadge）  
・Service Worker … オフライン起動とファイルのキャッシュ  
・Web App Manifest … PWAとしてインストールするための情報  
・Firebase Authentication … Googleアカウントでのログイン  
・Cloud Firestore … データの保存と、端末間のリアルタイム同期（オフライン対応）  

────────────────────────

■ 件数（アイコンの数字）のルール  

数えるもの  
・「🔥 今日」リストの未完了タスク  
・どのリストでも、期限が今日または過去の未完了タスク  
・繰り返し設定で今日出てきた未完了タスク  

数えないもの  
・期限が明日以降のタスク（「今日」リストに入っていても数えない）  
・期限なしで「今日」以外のリストにあるタスク  
・メモ、タスクの補足メモ  

更新のタイミング  
・タスクを追加／完了／戻したとき、すぐ更新  
・アプリを開いている間は30秒ごとに日付と時刻をチェックし、日付が変わったら再計算  
・アプリを完全に閉じている間は更新されない。次に開いたときに反映される  
・iPhoneで完了したタスクも、PCのアプリが開いていればすぐ反映されて数字が減る  

────────────────────────

■ 日付が変わったときに起きること  

・繰り返しタスクのうち、その日に当たるものが自動で出てくる  
・期限が今日以前になったタスクは、自動で「🔥 今日」の列へ移動する（元のリスト名は 📂 タグで表示）  
・手で「今日」以外の列に動かしたタスクは、自動では戻さない（件数には入る）  
・前日までに完了したタスクは画面から消える（データは残り、完了履歴から見られる）

■ 使い方  

タスクを追加する  
・各リストの下の入力欄にタイトルを入れて Enter  
・日付やメモも付けたいときは「詳しく」から  

タスクを完了する  
・タスク右側の「完了」ボタンを押す（行をクリックしただけでは完了にならない）  
・その日に完了したものは、列の下の「完了 n件」にまとまる。「戻す」で未完了に戻せる  

タスクを編集する  
・タスク名をクリックすると編集画面が開く  
・期限日：なし／今日／明日／カレンダーから選択  
・時刻（何時までに）：よく使う時刻のボタン、または直接入力。時刻を過ぎると赤字になる  
・繰り返し：毎日／平日のみ／毎週（曜日を複数選択可）／毎月（日付指定）／毎月末日／カスタム…  
・補足メモ：自由記述。URLはクリックで開ける  
・削除もここから  

繰り返しタスク（v3.5〜 「親」と「分身」）  
・親＝繰り返しの設定そのもの。作ったリストに「🔁 ◯◯　毎週 月　次は 10/12(月)」のカードでずっと残る。完了ボタンはなく、押すと設定（曜日・時刻・開始日・メモ・削除）を編集できる。件数には入らない  
・分身＝その日の分。開始日以降で、設定した曜日・日付になった日に「🔥 今日」へ直接出てくる（タグに親のリスト名）。完了しても親はそのまま  
・分身を開くと「今回ぶんを編集」になる（日付・時刻・メモなど）。繰り返しの設定は「親をひらく」から変える  
・例：月曜に「毎週 火」を開始日今日で作る → 月曜は何も出ない。火曜に分身が出る  
・やり残した回は赤字で残り、件数にも入る。次の回は別に1件ずつ出てくる  
・繰り返しを設定したとき、期限日の欄は「開始日」という表示になり、「いつから始めるか」の意味になる（ふつうは「なし」でOK）  
・カスタム…（v3.4〜、Google Keep のリマインダー風）：◯日／週間／か月／年 ごと。週は曜日を選ぶ、月は「毎月◯日／第◯◯曜日（最終も可）／月末」、年は開始日の月日。開始日、終了（しない／◯回で終わる／◯日まで）を決められ、設定内容が文章で出る  
・自分で削除したその日の分は復活しない  
・v3.4 までの繰り返し（タスク自体が初回分を兼ねていた形）は、開いたときに自動で親と分身の形にそろえる。もう出ている回は分身として残り、先の日付・日付なしの回は親が代わりに表示する  
・毎月の日付指定で、その月にない日（31日など）を選んだ場合は月末に出る  
・ヘッダーの「🔁 繰り返し」で一覧を見たり、設定を編集・削除できる  

タスクを動かす・並べ替える（v3.6〜）  
・リストの中の並び順は、手で並べた順。期限・時刻は並び順には使わず、今日への自動移動・赤字・件数にだけ使う  
・新しく入ってきたタスク（追加したもの、自動で「今日」に来たもの、繰り返しの分身）は一番下に入る  
・PC：タスクをドラッグして、同じリストの好きな位置や、別の列の好きな位置に落とす（落とす位置に金色の線が出る）  
・スマホ：タスクを長押しすると持ち上がるので、そのまま上下に動かして離す（ふつうに触るとスクロール）  
・リストの窓の並び順（v3.8〜）：PCは窓のタイトル（「🔥 今日」など）をつかんでドラッグし、入れたい窓の左半分（その前）か右半分（その後ろ）に落とす。iPhoneはタブを長押しして左右に動かす。「リストかんり」の↑↓と同じ並び順なので、PCとiPhoneで共通  
・または編集画面の「リスト」で選ぶ  

リストを管理する  
・ヘッダーの「🗂 リスト管理」から、名前・色・並び順の変更、追加、削除ができる  
・ウィンドウの枠の色もリストごとに選べる（v3.4〜）。「自」＝自動：繰り返しのあるリストはうすピンク、メモは水色、それ以外は白。「🔥 今日」は金色のまま  
・削除するときは、中のタスクをどのリストに移すか選んでから消す  
・リストには「タスク」と「メモ」の2種類がある（リスト管理の左のラベルで区別）。タスクはタスクのリスト同士、メモはメモのリスト同士でしか移動できない  
・「🔥 今日」は件数の基準なので削除できない（名前・色・順番は変更可）  

メモ  
・「メモのリスト」の列に付箋として並ぶ。件数には入らない  
・メモのリストは「🗂 リスト管理」→「＋ メモのリストを追加」でいくつでも作れる（例：会議メモ、リンク集）。名前・色・順番も変えられる  
・メモをクリックして開く編集画面の「入れるリスト」で、別のメモのリストへ移せる（メモのリストが2つ以上あるとき）  
・メモのリストを削除するときは、中のメモの移動先を選ぶ。メモのリストが1つしかないときは、中のメモも一緒に削除される  
・入力して Ctrl+Enter（または入力欄から離れる）で追加  
・クリックで編集・削除。URLはクリックで開ける  

完了履歴  
・ヘッダーの「✔ 完了履歴」で、完了したタスクを日付ごとに見られる  
・1件ずつ「戻す」「削除」ができる  
・左のチェックで選んで「選択したタスクを削除」でまとめて消せる（「すべて選択」もあり）  
・「🗑 すべて削除」で完了タスクを全部消せる（元に戻せない。未完了タスクと繰り返し設定は残る）  

けいけんち・レベル  
・タスクを「完了」するたびに、けいけんちが1入る。10たまるごとにレベルが1上がる（Lv1から）  
・「もどす」でけいけんちも1減る。完了履歴を削除してもけいけんちは減らない  
・けいけんちはクラウドに保存されるので、PCとスマホで同じ値になる（最初は、それまでに完了したタスクの数から始まる）  

勇者のプロフィール（v3.4〜）  
・画面右上の窓に、キャラの絵・なまえ・しょくぎょう・Lv・HP・MP・ちから・すばやさ・まもり・EXPゲージが出る（スマホは小さめで、ちから等は省略）  
・ステータスはレベルから計算するだけ（上がるだけ。ダメージなどはなし）。レベルアップすると「さいだいHPが ◯ あがった！」などが出る  
・窓をクリックすると、なまえ（初期「ゆうしゃ」）としょくぎょう（ナイト／まほうつかい／そうりょ／かりゅうど）を変えられる。しょくぎょうで絵とステータスの伸び方が変わる。PCとスマホで同じになる（meta/profile）  

たからばこ・どうぐ（v3.5〜）  
・タスクを完了すると、たまに（約10%）たからばこが見つかる。宝箱が開いて勇者が道具を頭の上に掲げる演出のあと、「◯◯を てにいれた！」と出る（「OK」を押すまで消えない）  
・道具は全40個のオリジナル（見た目は冒険の道具、名前と説明は仕事ネタ）。1種類1個で、まだ持っていない道具が出る。レア度（ふつう／レア／すごくレア／でんせつ）は出やすさの違い  
・1ページ20個。20個そろうと2ページ目が開く（それまで「？」）。一度開いたページは閉じない。全部そろったら宝箱は出ない  
・コマンドの「どうぐ」：マス目（5×4）に持っている道具が並ぶ。選ぶと（クリック・矢印キー）横の窓に名前・レア度・説明。使う機能はない  
・「もどす」と、そのタスクで手に入れた道具は返す（マスが空きに戻る）  
・道具はクラウドに保存（meta/items：counts＝持っている1／返した0、page＝開いたページ数）。v3.5.1 で1回だけ0からやり直し（reset351）  
・プロフィールの勇者は、昔のRPGのように その場で歩く（体を1ドット上下する2コマ。パソコン・スマホの「動きを減らす」設定のときは止まる）  

バージョン  
・今動いているバージョンは、アプリのウィンドウのタイトルバー（例：きょうのタスク（のこり3）ver3.4）と、「セーブ・アカウント」画面に出る（v3.4〜）  
・GitHubに新しい版が上がっていると、右上のプロフィールの窓の下に「▲ ver ◯.◯ が あります」が出る。押すと最新版に入れ替わる  

メッセージ  
・完了したときは、画面の上にメッセージが出て、しばらくすると引っ込む（クリックですぐ消える）  
・「きょうの タスクが ◯つ あらわれた！」は、その端末でその日はじめて開いたときだけ出る。「OK」を押すまで出ていて、押したらその日はもう出ない  
・アプリの中だけの表示で、PCの通知とは別  

バックアップ  
・ヘッダーの「💾 バックアップ」→「JSONで書き出す」で、全データをファイルに保存  
・「JSONを読み込む」で復元（今のデータは置き換わる）  
・バックアップのJSONはGitHubにアップしないこと

■ 公開とインストール（くわしくは 公開手順.md）  

1. GitHubでリポジトリを作る（Public）  
2. このフォルダの中身をアップロード →「Commit changes」  
3. Settings → Pages で、Branch を「main」「/(root)」にして Save  
4. 表示されたURL（https://ユーザー名.github.io/リポジトリ名/）を開く  
5. Chrome：アドレスバーのインストールアイコン／Edge：「…」→「アプリ」→「このサイトをアプリとしてインストール」  
6. タスクバー（Dock）にピン留めする  
7. iPhone：Safariで同じURLを開く → 共有ボタン →「ホーム画面に追加」  
8. どちらも初回は「Googleでログイン」で、会社のGoogleアカウントでログインする

■ アプリを更新するとき  

1. PCのこのフォルダで、変更したファイルを用意する  
2. GitHubのリポジトリで「Add file」→「Upload files」から、変更したファイルを同じ名前でアップロード →「Commit changes」  
3. 「Actions」タブの「pages build and deployment」が緑のチェックになるまで待つ  
4. アプリを閉じて開き直す。変わらなければ Ctrl+Shift+R、それでもだめなら10分ほど待ってから開き直す  

ポイント（バージョンの上げ方）  
・アップする前に、次の3か所を同じ番号に上げる（例：3.0 → 3.1）  
　app.js の APP_VERSION ／ version.json の version ／ sw.js の CACHE（kyou-task-v3.1）  
・こうしておくと、アプリ右上に「▲ 新しい ver があります」が出て、押すだけで最新版になる  
・v3.0から、ファイルを毎回GitHub Pagesに確認しにいくようにしたので、「10分待たないと反映されない」問題も起きにくくなった  
・リポジトリ名やGitHubのユーザー名を変えるとURLが変わり、アプリの入れ直しが必要になる（データはクラウドにあるので、ログインすれば戻る）。Firebaseの「承認済みドメイン」も合わせて確認する

■ 改修するときのルール（データを消さないために）  

アプリのファイルを差し替えても、入れてあるタスク・メモ・リストは残る。  
データはファイルの中ではなく、クラウド（Firestore）と各端末のブラウザ内に保存されているため。  
ただし、次のルールは必ず守ること。  

・app.js の保存名（STORE_KEY = kyou-task-data-v1）は変えない  
・sync.js のFirebaseの保存場所（users/ID/lists・tasks・rules・memos）の名前は変えない  
・firebaseConfig（接続先のFirebaseプロジェクト）は変えない  
・公開URL（GitHubのユーザー名・リポジトリ名）は変えない  
・データの形を変えるときは、app.js の DATA_VERSION を1つ上げ、MIGRATIONS に「古い形→新しい形」の変換を書き足す  
・項目は消したり名前を変えたりせず、「足す」だけにするのが基本  
・データの形が変わるときは、変換の前に元のデータが自動で退避される（kyou-task-data-backup-v◯）  
・万一データが読めなかったときも、消さずに退避してから起動する（kyou-task-data-broken-◯）  
・大きな改修をアップする前は、念のため「💾 バックアップ」→「JSONで書き出す」をしておく  

データが消えてしまうケース（改修とは関係なく）  
・Firebaseのプロジェクトやデータベースを削除したとき  
・Firebaseの画面（Firestore Database）でデータを直接消したとき  
・どちらかの端末で「JSONを読み込む」をしたとき（全データが置き換わる）  
※ブラウザのデータ削除やアンインストールでは、クラウドのデータは消えない（ログインし直せば戻る）

■ 注意点  

・初めて使う端末では、ログインにネット接続が必要  
・PCとiPhoneで同じタスクをほぼ同時に編集すると、後から保存した方の内容になる  
・iPhoneのホーム画面アプリでログインがうまくいかないときは、ログイン画面下の「別の方法でログイン」を試す  
・会社のGoogleアカウントでFirebaseを使っているので、会社の管理者からプロジェクトの存在は見える可能性がある  
・Firebaseは無料プラン（Spark）で使う。「アップグレード」「Blazeプラン」「お支払い情報」は設定しない  
・アイコンの数字の見え方は、OSやバージョンによって違う  
・Windows 11で数字が出ないときは、設定 →「個人用設定」→「タスクバー」→「タスクバーの動作」で、バッジ表示の設定を確認する
