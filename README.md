きょうのタスク  

アイコンに「今日の残りタスク数」を表示するToDoアプリ（PWA）。  
Google Keepの置き換えとして、自分のPC1台で使う想定。  

────────────────────────

■ どんなアプリか  

・Keepのような色つきの列（リスト）にタスクを並べて管理する  
・アプリのアイコン（タスクバー／Dock）に、今日やることの残り件数が数字で出る  
・完了するとすぐ数字が減り、0件になると数字が消える  
・ポップアップ通知は出さない。知らせる手段はアイコンの数字だけ  
・タスクとは別に、件数に入らない「メモ」（付箋）も置ける  

────────────────────────

■ つくり（構成）  

サーバーなしで、HTML／CSS／JavaScriptだけで動くWebアプリ。  
GitHub Pagesで公開し、Chrome／Edgeから「インストール」して独立したアプリとして使う。  

ファイル一覧  
・index.html … 画面の骨組み（ボード、編集画面などのダイアログ）  
・style.css … 見た目（パステル色の付箋カード、ボタンなど）  
・app.js … 動きのすべて（保存、件数計算、繰り返し、日付の切り替えなど）  
・manifest.webmanifest … 「インストール」できるようにするための設定（アプリ名、アイコン、色）  
・sw.js … Service Worker。オフラインでも起動できるようにファイルを保存しておく  
・icons/ … アプリのアイコン画像（192px、512px、マスカブル用、favicon など）  
・公開手順.md … GitHub Pagesへの公開とインストールの手順  
・README.md … このファイル  

データの保存先  
・ブラウザの中（localStorage）に保存される。保存名は「kyou-task-data-v1」  
・GitHubやほかのサーバーには一切送られない  
・公開されるのはプログラムだけ。他の人がURLを開いても空っぽのアプリが出るだけで、自分のデータは見えない  

使っている主な仕組み  
・Badging API … アイコンに数字を出す（navigator.setAppBadge）  
・Service Worker … オフライン起動とファイルのキャッシュ  
・Web App Manifest … PWAとしてインストールするための情報  

────────────────────────

■ 件数（アイコンの数字）のルール  

数えるもの  
・「🔥 今日」リストの未完了タスク  
・どのリストでも、期限が今日または過去の未完了タスク  
・繰り返し設定で今日出てきた未完了タスク  

数えないもの  
・期限が明日以降のタスク（「今日」リストに入っていても数えない）  
・期限なしで「今日」以外のリストにあるタスク  
・メモ、タスクの補足メモ  

更新のタイミング  
・タスクを追加／完了／戻したとき、すぐ更新  
・アプリを開いている間は30秒ごとに日付と時刻をチェックし、日付が変わったら再計算  
・アプリを完全に閉じている間は更新されない。次に開いたときに反映される  

────────────────────────

■ 日付が変わったときに起きること  

・繰り返しタスクのうち、その日に当たるものが自動で出てくる  
・期限が今日以前になったタスクは、自動で「🔥 今日」の列へ移動する（元のリスト名は 📂 タグで表示）  
・手で「今日」以外の列に動かしたタスクは、自動では戻さない（件数には入る）  
・前日までに完了したタスクは画面から消える（データは残り、完了履歴から見られる）  

────────────────────────

■ 使い方  

タスクを追加する  
・各リストの下の入力欄にタイトルを入れて Enter  
・日付やメモも付けたいときは「詳しく」から  

タスクを完了する  
・タスク右側の「完了」ボタンを押す（行をクリックしただけでは完了にならない）  
・その日に完了したものは、列の下の「完了 n件」にまとまる。「戻す」で未完了に戻せる  

タスクを編集する  
・タスク名をクリックすると編集画面が開く  
・期限日：なし／今日／明日／カレンダーから選択  
・時刻（何時までに）：よく使う時刻のボタン、または直接入力。時刻を過ぎると赤字になる  
・繰り返し：毎日／平日のみ／毎週（曜日を複数選択可）／毎月（日付指定）／毎月末日  
・補足メモ：自由記述。URLはクリックで開ける  
・削除もここから  

繰り返しタスク  
・設定した日になると、その日を期限にしたタスクが出てくる  
・やり残した回は赤字で残り、件数にも入る。次の回は別に1件ずつ出てくる  
・繰り返しを設定したとき、期限日は「いつから始めるか」の意味になる（ふつうは「なし」でOK）  
・毎月の日付指定で、その月にない日（31日など）を選んだ場合は月末に出る  
・ヘッダーの「🔁 繰り返し」で一覧を見たり、設定を編集・削除できる  

タスクを別のリストへ動かす  
・タスクをドラッグして別の列に落とす  
・または編集画面の「リスト」で選ぶ  

リストを管理する  
・ヘッダーの「🗂 リスト管理」から、名前・色・並び順の変更、追加、削除ができる  
・削除するときは、中のタスクをどのリストに移すか選んでから消す  
・「🔥 今日」は件数の基準なので削除できない（名前・色・順番は変更可）  

メモ  
・いちばん右の「✍ メモ」列に付箋として並ぶ。件数には入らない  
・入力して Ctrl+Enter（または入力欄から離れる）で追加  
・クリックで編集・削除。URLはクリックで開ける  

完了履歴  
・ヘッダーの「✔ 完了履歴」で、完了したタスクを日付ごとに見られる  
・1件ずつ「戻す」「削除」ができる  
・左のチェックで選んで「選択したタスクを削除」でまとめて消せる（「すべて選択」もあり）  
・「🗑 すべて削除」で完了タスクを全部消せる（元に戻せない。未完了タスクと繰り返し設定は残る）  

バックアップ  
・ヘッダーの「💾 バックアップ」→「JSONで書き出す」で、全データをファイルに保存  
・「JSONを読み込む」で復元（今のデータは置き換わる）  
・バックアップのJSONはGitHubにアップしないこと  

────────────────────────

■ 公開とインストール（くわしくは 公開手順.md）  

1. GitHubでリポジトリを作る（Public）  
2. このフォルダの中身をアップロード →「Commit changes」  
3. Settings → Pages で、Branch を「main」「/(root)」にして Save  
4. 表示されたURL（https://ユーザー名.github.io/リポジトリ名/）を開く  
5. Chrome：アドレスバーのインストールアイコン／Edge：「…」→「アプリ」→「このサイトをアプリとしてインストール」  
6. タスクバー（Dock）にピン留めする  

────────────────────────

■ アプリを更新するとき  

1. PCのこのフォルダで、変更したファイルを用意する  
2. GitHubのリポジトリで「Add file」→「Upload files」から、変更したファイルを同じ名前でアップロード →「Commit changes」  
3. 「Actions」タブの「pages build and deployment」が緑のチェックになるまで待つ  
4. アプリを閉じて開き直す。変わらなければ Ctrl+Shift+R、それでもだめなら10分ほど待ってから開き直す  

ポイント  
・sw.js の中の CACHE の名前（例：kyou-task-v4）を更新ごとに1つ上げておくと、古いキャッシュが確実に入れ替わる  
・リポジトリ名やGitHubのユーザー名を変えるとURLが変わり、別のアプリ扱いになる（データは引き継がれない）。変える前に必ずバックアップを書き出す  

────────────────────────

■ 改修するときのルール（データを消さないために）  

アプリのファイルを差し替えても、入れてあるタスク・メモ・リストは残る。  
データはファイルの中ではなく、ブラウザの中（localStorage）に保存されているため。  
ただし、次のルールは必ず守ること。  

・app.js の保存名（STORE_KEY = kyou-task-data-v1）は変えない  
・公開URL（GitHubのユーザー名・リポジトリ名）は変えない  
・データの形を変えるときは、app.js の DATA_VERSION を1つ上げ、MIGRATIONS に「古い形→新しい形」の変換を書き足す  
・項目は消したり名前を変えたりせず、「足す」だけにするのが基本  
・データの形が変わるときは、変換の前に元のデータが自動で退避される（kyou-task-data-backup-v◯）  
・万一データが読めなかったときも、消さずに退避してから起動する（kyou-task-data-broken-◯）  
・大きな改修をアップする前は、念のため「💾 バックアップ」→「JSONで書き出す」をしておく  

データが消えてしまうケース（改修とは関係なく）  
・ブラウザの「閲覧データの削除」でサイトデータ（Cookieとサイトデータ）を消したとき  
・アプリをアンインストールするときに「データも削除する」にチェックを入れたとき  
・公開URLが変わったとき  

────────────────────────

■ 注意点  

・データはこのPCのこのブラウザの中だけにある。ブラウザの「閲覧データの削除」でサイトデータを消すと、タスクも消える  
・ChromeとEdgeは別々に保存される（片方で入れたタスクは、もう片方には出ない）  
・アイコンの数字の見え方は、OSやバージョンによって違う  
・Windows 11で数字が出ないときは、設定 →「個人用設定」→「タスクバー」→「タスクバーの動作」で、バッジ表示の設定を確認する
